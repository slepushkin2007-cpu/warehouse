# Warehouse — Склад: партии и сроки годности

Модель предметной области склада с поддержкой партий, FEFO-отгрузки,
резервирования, температурного контроля и отчётов по потерям.

## Стек

- Java 21 (records, sealed, switch-выражения, pattern matching)
- Maven
- JUnit 5

## Модель

- `TemperatureMode` — enum температурных режимов: FROZEN, CHILLED, AMBIENT.
- `Category` — enum категорий товара с полями «температурный режим» и «срок хранения по умолчанию». Константа `YOGURT` переопределяет `describe()`.
- `Product` — товар. Идентифицируется неизменяемым `ProductId`.
- `Batch` — партия (record): номер, дата производства, срок годности, количество.
- `StorageZone` — зона склада с фиксированным температурным режимом.
- `Shipment` — sealed interface с двумя реализациями (`Fefo`, `Manual`) и полиморфным методом `totalQuantity()`.
- `Reservation` — резерв партии под заказ с таймаутом (TTL).
- `Warehouse` — фасад, вся логика склада.
- `WarehouseException` — доменное исключение с перечислением `Reason`.

## Глоссарий

Термины и сокращения, встречающиеся в коде и выводе демонстрации.

| Термин | Расшифровка | Что означает в проекте |
|---|---|---|
| SKU | Stock Keeping Unit | Уникальный артикул товара (SKU-001, SKU-002, ...) |
| ORD | Order | Идентификатор заказа под резерв (ORD-1) |
| QTY | Quantity | Количество единиц товара |
| TTL | Time To Live | Время жизни резерва в секундах до автоотмены |
| FEFO | First Expired, First Out | Правило отгрузки: первой уходит партия с ближайшим сроком годности |
| CHILLED | охлаждённый | Режим хранения 0..+6 C: молоко, йогурт, кефир |
| FROZEN | замороженный | Режим хранения -18 C и ниже: мороженое, замороженная рыба |
| AMBIENT | обычный | Режим хранения +15..+25 C: крупы, консервы |
| B-001 | Batch 001 | Номер партии товара (префикс B = batch) |
| FR-1 | Frozen zone 1 | Зона склада с замороженным режимом |
| CH-1 | Chilled zone 1 | Зона склада с охлаждённым режимом |
| AM-1 | Ambient zone 1 | Зона склада с обычным режимом |

## Возможности

### Базовый уровень

- Приём партии с проверкой совместимости температурного режима.
- FEFO-отгрузка: первой уходит партия с ближайшим сроком годности.
- Остаток товара на заданную дату (без учёта просроченных партий).
- Список просроченного на дату.
- Исключения при отгрузке сверх остатка или при отсутствии неистёкших партий.

### Повышенный уровень

- Резервирование партий под заказ с отменой резерва по таймауту (TTL).
- Отчёт «сгорит в ближайшие N дней» с суммой потерь.
- Проверка совместимости категории товара и температурного режима зоны склада.

## Запуск

Сборка и тесты:

    mvn clean test

Ожидаемый результат: Tests run: 14, Failures: 0, Errors: 0.

Демонстрация:

    mvn compile
    java -cp target/classes com.example.warehouse.app.Demo

Javadoc:

    mvn javadoc:javadoc

HTML откроется в target/site/apidocs/index.html.
